# Changelog

## 1.0.0 — 2026-09-17 (dev / testing)

- Initial version for dev testing of the WiFi device connection: pymobiledevice3
  engine image (connect by IP over classic lockdown TCP 62078, no USB / no
  netmuxd / no mDNS, cross-subnet); upload of a jitterbugpair pairing file with
  device name, IP and optional backup encryption password; per-device backup
  with retention; device list with pairing/backup status; settings UI (EN/DE).
  End-to-end backup against a physical device is not yet verified.
